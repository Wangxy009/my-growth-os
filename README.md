# My Growth OS

个人成长管理 Web App 的第一阶段可用版。

## 当前版本

这是一个无需安装依赖即可运行的本地动态 Web 应用。首页是总览，各模块使用独立页面，并通过本地 SQLite 与浏览器缓存共享状态。

当前包含：

- 首页总览（学习、健康和资源数据联动）
- 明日计划候选与确认
- 三门固定听课课程的硬性标记
- 其他课程时间作为可学习窗口的示例
- Todo 任务
- 番茄钟
- 学习时长统计
- 考研、实习、论文、留学路线
- GitHub 资源和作品集入口（分类、许可证、复现/复用说明）
- 健康计划、周运动统计、饮食、体脂和生理期私密记录

本阶段收口：12 个独立页面、共享状态、备份恢复、计划确认、间隔复习、RSS/GitHub/Crossref 连接器、可安装 PWA 外壳和可选 Agent 对话均已完成基础验收；本地回归测试共 40 项通过。服务器会保护 SQLite、WAL、环境变量和开发目录，不通过静态路由公开。

## 本地运行

SQLite 数据层使用 Node.js 内置的 `node:sqlite`，建议 Node.js 版本为 24 或更高。

推荐在项目目录启动本地服务器：

```bash
node server.js
```

也可以双击项目目录里的 `start-server.command`，它会显示 Node 版本、项目目录和实际端口；如果启动失败，窗口会保留错误信息。

然后访问终端输出的地址，通常是 `http://127.0.0.1:4173/index.html`。如果 4173 已被占用，服务器会自动尝试 4174、4175、4176，并在终端显示实际地址。

可以访问 `http://127.0.0.1:4173/api/health` 检查服务是否已启动；如果端口发生变化，请使用终端输出的实际端口。

运行本地回归测试：

```bash
node --test tests/*.test.js
```

Agent 页支持可选的 OpenAI 兼容接口，当前默认按豆包（火山方舟 Ark）配置。项目目录中的 `.env.local` 填写：`AI_API_BASE_URL=https://ark.cn-beijing.volces.com/api/v3`、`AI_MODEL=ep-...`（方舟推理接入点 ID）和 `AI_API_KEY=...`（方舟 API Key）。先在火山方舟控制台创建/启用豆包推理接入点并创建 API Key；不要把密钥贴进网页或聊天，也不要提交到仓库。`.env.local` 已加入忽略规则，服务器也禁止通过静态文件路由读取它。模型调用可能产生费用，用户消息和最近 12 条对话会发给配置的服务商；学习摘要默认关闭、逐次授权，健康模块档案不包含在摘要中。对话只保留在当前标签页内存，AI 生成的英语/技能/科研记录建议必须手动确认后才写入本地数据。

资源页的仓库查询器会通过本地服务器请求 GitHub 的公开 API，读取仓库元数据、Issues 和文本文件。元数据只会填入表单，必须手动确认后才保存到本地；Issues 和文件内容只在页面显示。接口示例：`/api/github/repository?url=...`、`/api/github/issues?url=...`、`/api/github/file?url=...&path=README.md`。

也可以直接打开 `index.html`，但本地服务器更适合验证页面之间的共享数据。

## 页面结构

- `index.html`：总览、今日任务、番茄钟、周统计、重要事项倒计时和全模块备份/恢复
- `planner.html`：课程表、明日候选计划和 23:00 确认；候选任务可逐项排除并调整本次分钟数，确认后锁定
- `exam.html`：北大软微金融科技、北大经济学院金融两条路线；支持章节/刷题记录与 1/3/7/14 天间隔错题复习，连续掌握后归档，仍不会则次日重练
- `english.html`：雅思训练记录、从英文 RSS 同步的精读素材和一键加入精读计划；训练计划会同步到总计划，实际词汇量须手动填写，英语错题支持 1/3/7/14 天间隔复习
- `research.html`：可选导入 12 步论文起步清单、工作流状态推进、阅读状态循环、研究日志和 Crossref 公开书目搜索（需联网）；起步事项不预设截止日期
- `skills.html`：Excel、Python、SQL、金融数据分析四条分阶段学习路径，可把当前步骤加入总计划；项目包含可勾选的复现清单
- `applications.html`：实习、保研、留学起步清单与事项跟踪；可推进申请状态、记录每次跟进及下一步，并可编辑截止日、材料备注和作品关联
- `knowledge.html`：金融、计算机、绿色金融与 AI+金融的 12 讲连续基础路径，含逻辑链、案例、简答、公开通用参考资料和学习记录
- `news.html`：时政、财经和经济学人阅读记录；首次使用可一键配置 6 个公开 RSS 推荐源（BBC 世界/商业/科技、中国日报、Federal Reserve、Bank of England），本地服务器每小时尝试刷新；文章进入待确认收件箱后再由你保存。外站 RSS 可用性会变化，失败原因会显示在来源状态中
- `health.html`：运动、饮食、体脂和生理期记录；无氧及骑行/游泳按周统计，攀岩按月目标单独统计
- `resources.html`：GitHub 资源、许可证和复用方式

## 当前数据边界

通过本地服务器访问时，数据会保存到项目目录下的 `growth-os.sqlite`，页面同时保留 `localStorage` 缓存以支持离线打开。离线编辑会显示待同步状态，并在本机服务器恢复后自动重试。PWA 只缓存公开静态外壳，不缓存 `/api`、SQLite、环境变量、备份文件或健康记录。SQLite 只绑定在 `127.0.0.1`，不会自动同步到云端；健康记录默认本地私密保存。GitHub 资源、论文结论、投稿和重大计划调整仍需要手动确认。

当前已接入本地 SQLite 数据层、`localStorage` 离线缓存、GitHub 公开仓库/文件/Issues 查询、Crossref 书目查询和 RSS/Atom 新闻源读取。已保存新闻源可以刷新到“待确认收件箱”，确认后才会进入阅读列表。新闻源需要使用你有权访问的 HTTPS 地址；经济学人等付费内容不会被绕过。新闻页支持用户主动授权后的浏览器提醒，但页面关闭后不会后台运行；后续可接入系统级定时任务和 AI Agent。远程资源导入、新闻自动推送和 AI 写入数据都需要单独配置外部服务，并保留用户确认步骤。外部新闻源的可用性受网络、站点限流和源站更新影响，失败会显示来源错误。

首页提供完整 JSON 数据备份与恢复：导出包含所有模块数据（包括健康记录），只下载到本机；恢复会覆盖现有数据，并在覆盖前自动下载当前快照。备份文件可能含敏感信息，应妥善保管，不要提交到公开仓库。

Agent 对话使用本机服务器代理配置的模型服务，不是 Codex 账户或 ChatGPT 订阅的自动复用；尚未配置时只保留原有规则式进度同步。

英语精读素材从新闻页已保存/待确认的英文 RSS 项目生成，精读计划需用户点击加入。金融知识页目前是本地精选的 12 讲连续基础路径，技能页提供四条分阶段基础路径和 5 个轮换项目提示，学习步骤可逐个加入总计划。这些学习内容不是 AI 实时生成或远程每日更新；金融知识与考试课程大纲需交叉核对，不能替代课程讲义。GitHub 项目作为独立参考链接，当前没有把第三方代码嵌入或自动复制到本应用。
