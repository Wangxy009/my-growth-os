# 模块地图：My Growth OS

## 产品方向

这是一个先服务本人、以后可作为个人作品集公开介绍的成长管理应用。实现遵循“先把模块完整接上，再分别优化”的原则：现阶段确定模块边界、数据项和相互关系，不提前锁定复杂的视觉设计或学习方案细节。

## 路线与优先级

发展路径并列推进，排程建议优先级如下：

1. 考研
2. 实习
3. 保研
4. 留学（香港、英国、德国，作为保障路线）

论文、雅思、技能和金融科技知识作为横向能力模块服务多条路线。具体每周时间配比应在路线模块优化阶段再与你确认，不在模块盘点阶段假设。

## 考研子模块

- 北大软微金融科技：英语一、数学二、831经济学综合。
- 北大经济学院金融：英语二、数学三、431金融学综合。

每科后续可以扩展：大纲、阶段、章节、题量、正确率、错题、复习日期、下个里程碑。当前只建立路线和科目进度，不自动推导学习强度。

## 雅思子模块

- 词汇：雅思词汇真经、考研英语红宝书、复习批次。
- 听力：练习来源、篇数、正确情况。
- 阅读：文章/套题、正确率、错题。
- 写作：任务类型、练习稿、反馈。
- 口语：话题、练习次数、反馈。
- 目标：7.0+；最晚2027年7月前取得成绩。
- 当前数据表单先作每日练习日志，不等同于系统化备考计划。

## 论文科研子模块

1. 可选导入 12 项论文起步清单：从兴趣/导师交流、研究问题和文献检索到数据、研究设计、写作、导师反馈与投稿规范。
2. 起步清单按标题或模板 ID 去重，不臆造截止日期；用户可自行添加事项及期限。
3. 工作流事项支持“待开始 → 进行中 → 已完成 → 重新打开”的状态推进，也支持删除。
4. 研究方向与候选选题、研究问题、文献库/阅读状态/笔记、Crossref 公开书目搜索、数据与方法、研究日志。
5. 投稿选择、论文结论、数据许可与研究伦理需要用户和导师核实；工具不自动代替判断或提交。

选题方向候选：金融科技、绿色金融、数据分析、AI与金融。论文结论和外部投稿动作必须由用户把关。

## 技能与作品集子模块

- 技能：Excel、Python、SQL。
- 金融数据分析作为综合实践路径；四条本地基础路径均按“完成当前阶段后解锁下一步”推进，不会一键堆入整套任务。
- 用户可把当前技能步骤加入全局任务/明日候选计划，并在完成后同步标记任务完成；排程仍由用户每晚确认。
- 项目方向：贴近金融科技、绿色金融、实习求职和复试。
- 项目复现清单覆盖问题与验收口径、数据来源/许可、清洗与字段质量、结果复核、README/环境/复现步骤；勾选进度会同步项目完成度。
- 旧项目首次启用清单时保留已有进度作为基线，不将旧数据直接清零。
- 每个项目有目标、数据来源、步骤、代码/文档、结果、复现方法、展示状态。
- 第三方开源资源记录来源和许可证；私人健康与学习记录不进入公开作品集。

## 其余模块初步范围

- 实习：岗位跟踪、申请状态、面试安排、面试复盘。
- 保研：资格条件、成绩/排名材料、科研竞赛、夏令营与预推免进度。
- 留学：国家/地区、院校项目、截止日期、语言和申请材料清单。
- 金融科技知识：12 讲本地精选顺序路径，覆盖货币时间价值、债券/组合风险、信贷、数据库/SQL/Python、信用模型治理、绿色风险和可复现分析。
- 每讲呈现前置主题、逻辑链、案例与简答；提交至少 5 字的个人理解后才推进，学习记录与“已掌握”状态分开。
- 可将当前讲加入总计划；这是个人学习辅助，不替代 431/831 大纲、课堂讲义或教师要求，也不是 AI 实时内容。
- 新闻：考研政治时政与财经新闻分开，记录来源、日期和摘要；外刊原文遵守版权。
- 健康：力量训练、骑行/游泳、攀岩，以及饮食、体脂和周期手动记录；不作医疗诊断。
- GitHub资源：学习、项目参考、工具、Agent等分类，附使用说明、许可证和复用判断。
- Agent团队：总览与专业角色、规则式同步和可选 AI 对话。仅英语/技能/科研日志建议可由用户点击确认后写入；学习摘要逐次授权发送，健康模块档案不发送。

## 当前开发顺序

1. 共用底座：独立页面、课表/计划、任务/专注、重要事项倒计时、SQLite 与浏览器缓存、跨模块状态、数据备份与恢复。
2. 模块初版：考研、英语、论文、技能与作品集、申请追踪、金融科技知识、新闻/RSS、健康、GitHub 资源和 Agent 工作区均已有独立入口与基本记录能力。
3. 内容更新：新闻 RSS、GitHub 公开 API 和 Crossref 书目查询可在本地服务器及网络可用时使用；需要用户配置合法来源的内容按确认流程进入个人库。
4. 暂缓项：AI 服务商/中转站 API 接入留到本阶段最后；后台推送、AI 自动总结和多设备同步还需外部服务或单独方案。
5. 完成基础配置后，再按模块逐一优化具体策略、提醒、内容质量和流程。
6. 统一 UI 设计、手机适配和应用打包仍放在模块功能确认之后。

具体暂缓事项记录在 `docs/BACKLOG.md`：431/831 教材版本与章节映射、AI 服务商或中转站接入，以及新闻后台推送和 AI 总结验证。

## 重要约束

- 财政学、金融科技、应用随机过程是固定听课时间。
- 其他课程时间默认可安排学习。
- 原课表只提供节次，未提供节次对应钟点。
- 每日计划在用户确认前为候选。
- 正常学习目标3—4小时，冲刺日最多5—6小时。
- 23:00作为每天计划确认时间。
- 默认本地存储；私人健康信息不公开。
- 模块范围先确定，具体规则、强度、提醒和界面逐模块确认。
